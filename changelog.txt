v1.0.2
- New: "Hide watched" on the context menu. It is on every item, applies to
  every listing, and stays set until you turn it off again.
- New: "Mark as played" / "Mark as unplayed" and "Reset resume position" on
  the context menu. Both act on AudioBookShelf, not on Kodi's own database,
  so the change follows you to your other devices.
- Fix: the sleep timer flashed the screen back up as it stopped playback,
  so you were left looking at a lit UI at the moment it was meant to go
  dark.
- Fix: the server address is now greyed out while you are signed in.
  Editing it would have pointed your stored tokens at a server that never
  issued them. Sign out to change it.
- Settings: General is the first tab, and it is one flat list — the group
  headings and the separator between them are gone.

Finished books still do not show a watched tick. Kodi draws that overlay
only for items in its own library, and add-on items are not in it. Books
you are part-way through are unaffected — those come from the resume
point, which Kodi does honour.

v1.0.1
- Fix: "All Books" said "Title (A-Z)" and showed a jumble. The default sort
  key was one AudioBookShelf does not have, and an unknown key makes the
  server return rows in no order at all rather than reporting a problem.
- Fix: three more sort options were silently doing nothing for the same
  reason. Narrator and Series are removed — the server has no key for
  either — and "Recently updated" is now "Recently changed on disk", which
  is what it actually sorts by.
- New sort: "Recently listened".

Kotome 1.0.0 is the first release under this name. It was previously called
Koshelf (plugin.audio.koshelf), which is no longer maintained. Kotome
installs as a separate add-on and carries nothing over, so sign in once and
set your preferences; uninstall Koshelf whenever you like. Entries below
1.0.0 are Koshelf's history, kept for the record.

v1.0.0
Sleep timer
- The screen overlay is gone. It could deadlock Kodi: the full-screen
  window it drew outlived the service, survived the add-on being disabled,
  and once ownerless the next Back press froze the whole UI unrecoverably.
  The timer now uses Kodi's own screensaver and puts your screensaver
  settings back when you return.
- Removed Screen off (HDMI-CEC): it needs peripheral.libcec, which does not
  exist on Android and is not on a stock desktop Kodi.
- "Screen off (Android / Google TV)" is now "Turn the display off
  (Linux/X11 only)", which is where DPMS actually exists. On Android the
  screensaver is used instead.
- New "Screensaver: my usual one" mode.
- Fix: the idle-seconds setting used an operator Kodi does not have, so the
  whole dependency was discarded and the setting showed even with the
  screen action set to None.

Speed
- Browsing is roughly ten times faster. Every listing used to spend
  0.8-1.6 s starting up before doing any work, most of it importing a
  library that a short-lived plugin process cannot benefit from. Root menu
  0.91 s -> 0.08 s, Authors 1.08 s -> 0.09 s on a desktop; an ARM box saves
  considerably more.
- The cached token is no longer checked with a throwaway API call on every
  listing, and your progress data is fetched once rather than per folder.

Browsing
- The sort menu now works. Picking "Recently added" returned the right page
  from the server and then Kodi re-sorted it alphabetically.
- The sort picker moved to the context menu, so it is on every item and
  every page rather than only at the top of page one. More sorts: author
  Z-A, narrator, series, oldest added, published year ascending, size.
- In-progress books and episodes carry a real Kodi resume point instead of
  "[42%]" in the title, so skins show their own progress indicator and Kodi
  offers Resume / Start from beginning. Finished books are marked watched.
- Narrator, duration, genre and year moved out of the label into the info
  tag, where the skin can lay them out.
- Every folder has an icon. Books and Continue Listening have their own;
  the rest use Kodi's, so they match whatever skin you run.
- Books and podcasts with no cover on the server show a placeholder instead
  of a broken image.
- Added fan art. Note that some skins have fanart backgrounds turned off —
  in Contuary it is Settings, "No fanart".
- Removed the Music player (PAPlayer) option. It was not supported.
- Fix: a book whose published year is a full date crashed the listing.

Account
- Your password is no longer stored. Sign in is a button in Settings that
  asks once, exchanges it for tokens, and forgets it.
- Uses AudioBookShelf's current token model — a one-hour access token plus
  a refresh token, renewed automatically and again before playback starts.
  The previous login used a token the server marks deprecated.
- Settings shows which server and account you are signed in to, with Test
  connection and Sign out.
- The server address accepts a bare host name, host:port, or a full URL,
  and is checked before you are asked for a password.
- New: Verify HTTPS certificate, for a server behind a self-signed one.
- Each install identifies itself to the server with its own device ID.

Fixes
- Opening Settings from the add-on menu, or hitting an unrecognised route,
  left a directory handle open; a favourite or library node pointing at
  either could hang.
- A trailing slash on a plugin URL broke any route whose last parameter was
  not the action.

v0.20.0
- Sleep timer screen options restructured: single "Screen action" setting
  with five modes — Screensaver: Black, Screensaver: Dim, Screen off
  (HDMI-CEC), Screen off (Android / Google TV), or None. Replaces the
  previous dim toggle + screensaver picker + display-off checkbox.
- Fix: screensaver no longer pulsates. The screen action now fires once
  per idle period and only re-arms when the user interacts, instead of
  repeatedly calling ActivateScreenSaver every 250 ms.
- Fix: sleep_last_preset now has the required <control> tag for Kodi v22
  (was causing repeated parse errors in the log).
- Custom sleep timer shows a numeric keypad instead of a full text keyboard.
- If a custom duration was previously used, it appears in the preset list
  with "(last used)" and is preselected.
- Fix: widget URLs with a trailing slash (e.g.
  plugin://plugin.audio.koshelf/?action=continue_listening/) now route
  correctly.
- Remove the "Comment:" field from book and podcast episode info dialogs.
  Descriptions are still shown via VideoPlayer's Plot field during playback.
- Podcast directory items now have MusicInfoTag (title, artist, genres) and
  cover art — the i (info) button works.
- Author items now have MusicInfoTag (artist name, bio) — the i (info)
  button works.

v0.19.0
- Sleep timer with screen-dim and volume ramp-down. While playing, the
  "Sleep timer" row in the Koshelf root menu opens a dialog with
  presets (5/10/15/30/45/60/90 min), End of chapter, Custom..., and
  Cancel timer. The last-used preset is highlighted on next visit.
- While a sleep timer is active, Kodi's screensaver is temporarily
  swapped for a black or dim mode that activates after a shorter idle
  period (Settings → Sleep timer). The original screensaver is
  restored when the timer expires or is cancelled. Crash-recovery
  restores it on next service start if Kodi was killed mid-timer.
- Volume fades to zero over the last N seconds before the timer fires
  (default 30, configurable, 0 to disable). Adjusting the volume
  manually during the ramp cancels it for the rest of the timer and
  doesn't restore on cancel.
- Optional: send a CEC standby on expiry to power off the connected
  TV (HDMI-CEC required). Off by default.

v0.18.1
- Restore audio-only categorisation. The addon now shows only under
  Music add-ons, not Video add-ons; the v0.18.0 dual categorisation
  caused the i (info) button to no-op when the addon was launched from
  Video add-ons (DialogVideoInfo never opened).
- VideoPlayer playback is still the default. Player core selection is
  driven by the ListItem's VideoInfoTag, not by the addon's <provides>
  category, so removing "video" from <provides> doesn't affect which
  player core handles playback.

v0.18.0
- Video player is the default again. With inputstream.tempo 0.3.10's
  dynamic ptsStart (computed from popped-packet pts/dispTime), the
  Video player OSD now tracks content time at non-1× tempo instead of
  ticking at wall-clock — the regression that caused v0.14.0 to drop
  the video path. The Video player also brings the richer now-playing
  UI (cover-art and visualisation fanart) and surfaces embedded source
  chapters via the music OSD's Previous/Next chapter buttons.
- Music player is still available as an opt-in under
  Settings → Playback → Player. PAPlayer's lighter pipeline is kept
  for users who prefer it; resume, tempo, position sync, and per-book
  speed tracking work in either mode. <provides> now includes "video"
  in addition to "audio".
- Resume works the same in both modes. The Video player branch sets
  StartOffset (ms) plus ResumeTime/TotalTime; the Music player branch
  keeps audiobook_bookmark. Both set inputstream.tempo.start_time so
  the addon's player-agnostic seek-hold prevents start-of-file audio
  leaks before the resume seek lands.
- Requires inputstream.tempo 0.3.10 or newer.

v0.17.2
- Fix: a failed replay from Continue Listening was erasing the book's
  resume position. When PAPlayer couldn't open the stream (e.g.
  transient HTTP error), the service would run its close-session path
  with last_time=0 and sync that back to ABS, clobbering the bookmark.
  Now the close path skips sync_session when last_time < 5 s while
  start_time > 30 s — playback obviously never resumed, so don't
  pretend the user listened to the first 0 s.

v0.17.1
- Move the [NN%] progress indicator to after the title in library
  listings (All Books, Series detail, Author books, Collections,
  Podcast Episodes, Recent Episodes). Leading '[' was sorting before
  A-Z in Kodi's title sort, clustering in-progress items at the top
  regardless of name. Continue Listening still shows the indicator
  as a prefix — that view is ordered by last-played, not title.
- Sanitise descriptions before they reach Kodi's Info dialog. ABS
  often imports descriptions with HTML markup (<p>, <b>, <i>, &amp;,
  &nbsp; etc.) copied from Audible; Kodi was rendering the tags
  verbatim. Now parsed to plain text with paragraph breaks preserved,
  HTML entities decoded, and NBSP normalised to ASCII space.

v0.17.0
- Books and podcast episodes in library listings now show a
  "[NN%]" prefix when in progress — same format Continue Listening
  uses, so an item looks the same whether you reach it via resume
  or by browsing. Covers All Books, Series, Authors, Collections,
  Podcast Episodes, and Recent Episodes.

v0.16.0
- Resume no longer leaks a fraction of a second from the start of the
  book. On resume, Koshelf sets inputstream.tempo.start_time in addition
  to the usual audiobook_bookmark property. inputstream.tempo 0.3.6+
  uses that hint to hold packet output until PAPlayer's bookmark seek
  arrives (or a 2 s safety timeout) — so no pts=0 audio reaches the
  sink before the seek lands. Requires inputstream.tempo 0.3.6.

v0.15.0
- Library listings now sort server-side via ABS, so the order is
  consistent across pages instead of only within the loaded page.
  A "[ Sort: ... ]" item at the top opens a picker (Title, Author,
  Recently added/updated, Duration, Published year, Random). The
  choice is preserved through pagination.
- Background art: listing items expose their cover as fanart so
  skins with a blurred-fanart visualization (Estuary and similar)
  use the book/podcast cover as a backdrop during playback.
- Info dialog: books in Continue Listening now include the book
  description, and every playable item reports mediaType='song' so
  most skins show the full music Info dialog with description.

v0.14.0
- Removed the Player setting and the Video player path. PAPlayer is now
  the only player. The video path was originally added to chase a
  tempo-tracking OSD, but its state.time progressed at wall-clock rather
  than tempo-adjusted rate, so it offered no benefit over the music
  player path.

v0.13.0
- New Player setting: choose between the Music player (PAPlayer, default)
  and the Video player (VideoPlayer). Tempo, resume, position sync, and
  per-book speed tracking all work in both modes. The video player path
  uses VideoPlayer's StartOffset for resume plus a service-side
  onAVStarted fallback. The addon now declares <provides>audio video</provides>.
- Requires inputstream.tempo 0.3.1 or newer so the OSD position tracks
  content time at non-1× tempo.

v0.12.3
- Resume playback uses PAPlayer's native audiobook_bookmark property.
  PAPlayer seeks before audio output begins — no race conditions, no
  Python seek hack, no C++ intercept.
- Rename KoShelf → Koshelf throughout.
- Configurable items per page (25–500, default 100) for full client-side
  sorting of large libraries.
- Episode title shown on OSD (uses session.displayTitle); album set to
  podcast name for episodes.
- Description available in info dialog (press i) via setComment() in all
  browsing routes and during playback.
- Now playing root label: speed at front, always two decimal places.
- Max speed lower bound changed from 1.5x → 1.0x (allows disabling tempo).
- Speed step description updated to reference PgUp/PgDn keys.
- Sync guard prevents overwriting a valid resume position with 0.
